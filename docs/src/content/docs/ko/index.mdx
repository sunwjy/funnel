Funnel은 핵심 퍼널 이벤트를 **하나의 인터페이스로 연결된 모든 도구에 전송**하는 마케팅 분석
라이브러리입니다. 이벤트는 GA4 표준으로 한 번만 작성하고, 각 플러그인이 대상 플랫폼의 네이티브
형식으로 변환합니다.
