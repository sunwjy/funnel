이 가이드들은 [빠른 시작](/ko/start-here/quickstart/)을 넘어, 실제 애플리케이션에서 필요한
내용을 다룹니다. 가이드는 계속 추가되는 중입니다 — 이 섹션은 how-to 자료를 위한 곳이며, 자세한
API 세부는 [레퍼런스](/ko/reference/)를 보세요.

주제:

- [**핵심 개념**](/ko/guides/core-concepts/) — `Funnel`, 플러그인, `EventContext`의 관계.
- [**첫 이벤트 추적**](/ko/guides/first-events/) — 이벤트 이름, 파라미터, GA4 스키마.
- [**여러 플러그인 연결**](/ko/guides/multiple-plugins/) — 여러 플랫폼을 한 번에 연결.
- [**프레임워크 연동**](/ko/guides/framework-integration/) — React + Vite, Next.js, 바닐라 HTML.
- [**서버사이드 & 중복 제거**](/ko/guides/server-side-dedup/) — Meta Conversions API와 서버사이드 GTM.
- [**SSR 주의사항**](/ko/guides/ssr/) — 플러그인이 `typeof window`로 가드하는 이유.
- [**트리쉐이킹 & import**](/ko/guides/tree-shaking/) — 배럴 vs 서브패스 import.

특정 플랫폼 설정 단계를 찾고 있나요? [플러그인 카탈로그](/ko/plugins/)로 가세요.
