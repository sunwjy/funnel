레퍼런스는 Funnel의 안정적인 표면을 설명합니다. 막 시작했다면 [가이드](/ko/guides/)가 더
부드러운 경로이고, 정확한 이름과 구조가 필요할 때 이곳을 보세요.

- **`EventMap`** — GA4 기반의 이벤트 이름과 파라미터 카탈로그.
- **`Funnel`** — 디스패처 클래스: `new Funnel({ plugins })`, `initialize()`, `track()`.
- **`FunnelPlugin`** — 모든 플러그인이 구현하는 인터페이스.
- **`EventContext`** — 모든 플러그인에 전달되는 이벤트별 컨텍스트(생성된 `eventId` 포함).

자세한 페이지는 사이드바에 나열됩니다.
