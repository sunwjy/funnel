These guides go beyond the [Quickstart](/start-here/quickstart/) and cover the things you'll
reach for in a real application. More guides are being added — this section is the place for
how-to material, not exhaustive API detail (see the [Reference](/reference/) for that).

Topics:

- [**Core concepts**](/guides/core-concepts/) — how `Funnel`, plugins, and `EventContext` relate.
- [**Tracking your first events**](/guides/first-events/) — event names, parameters, and the GA4 schema.
- [**Adding multiple plugins**](/guides/multiple-plugins/) — connecting several platforms at once.
- [**Framework integration**](/guides/framework-integration/) — React + Vite, Next.js, and vanilla HTML.
- [**Server-side & deduplication**](/guides/server-side-dedup/) — the Meta Conversions API and server-side GTM.
- [**SSR considerations**](/guides/ssr/) — why plugins guard on `typeof window`.
- [**Tree-shaking & imports**](/guides/tree-shaking/) — barrel vs. subpath imports.

Looking for setup steps for a specific platform? Head to the [Plugins catalog](/plugins/).
